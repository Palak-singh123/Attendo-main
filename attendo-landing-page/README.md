# Attendo Landing Page

A responsive, standalone AI attendance landing page, customized with Attendo branding and its face/voice attendance workflows.

## Files
- `index.html` — page content
- `style.css` — responsive styles
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in your browser, or use VS Code Live Server.

## Before publishing
Search for the `Open Attendo` links in `index.html` and replace the placeholder `#get-started` destination with your deployed Attendo app URL. The GitHub button currently links to `https://github.com/Palak-singh123/Attendo-main`.
